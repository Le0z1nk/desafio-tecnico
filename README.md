# Desafio Técnico

## Descrição

Este projeto é uma aplicação web desenvolvida em **Spring Framework** utilizando **Maven** como gerenciador de dependências. A aplicação foi criada como parte de um desafio técnico, seguindo boas práticas de desenvolvimento em Java e arquitetura RESTful.

---

## Tecnologias Utilizadas

* **Java 17**
* **Spring Boot**
* **Spring Data JPA**
* **Hibernate**
* **Maven**
* **SQLite**
* **REST API**

---

## Pré-requisitos

* Java 17 ou superior
* Maven 3.6+
* Git
* IDE de sua preferência (IntelliJ, Eclipse, VS Code)

---

## Instalação e Execução

1. Clone o repositório:

```bash
git clone https://github.com/Le0z1nk/desafio-tecnico.git
cd desafio-tecnico
```

2. Compile o projeto com Maven:

```bash
mvn clean install
```

3. Execute a aplicação:

```bash
mvn spring-boot:run
```

A aplicação será iniciada em `http://localhost:8080`.
